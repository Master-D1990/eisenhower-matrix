Datenschutzerklärung

Stand: 2. November 2026

Kurz gesagt

Eisenhower Matrix+ ist ein Werkzeug, das vollständig in deinem Browser läuft. Es gibt keinen Server und kein Konto bei uns. Wir erhalten, speichern und verkaufen keine Daten von dir.

Daten im Browser

Deine Matrix wird im Speicher deines Browsers (localStorage und IndexedDB) abgelegt, damit sie beim nächsten Besuch wieder da ist. Diese Daten verlassen dein Gerät nicht. Du kannst sie jederzeit löschen, indem du die Websitedaten im Browser entfernst.

Dateien auf deinem Gerät

Wenn du eine Datei speicherst oder öffnest, liest und schreibt das Tool nur diese eine Datei, die du selbst ausgewählt hast.

Google Drive (freiwillig)

Du kannst deine Matrix in deinem eigenen Google Drive speichern. Nur wenn du das ausdrücklich verbindest, gilt Folgendes:

  • Zugriff: Das Tool verwendet nur die Berechtigung drive.file. Es sieht und bearbeitet ausschliesslich Dateien, die du mit dem Tool angelegt oder darin ausgewählt hast. Auf deine übrigen Dateien hat es keinen Zugriff.
  • Verwendung: Die Daten werden nur gelesen und geschrieben, um deine Matrix zu laden und zu speichern. Sie gehen direkt von deinem Browser zu Google und zurück, nicht über einen Server von uns.
  • Speicherung: Das Zugangstoken bleibt nur im Browser und läuft nach kurzer Zeit ab. Wir speichern keine Google-Daten.
  • Weitergabe: Wir geben keine Google-Daten an Dritte weiter und verwenden sie nicht für Werbung, Profile oder das Training von KI-Modellen.
  • Widerruf: Du kannst den Zugriff jederzeit unter myaccount.google.com/permissions entziehen.

Die Nutzung und Übertragung von Informationen, die von Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Hosting

Die Seite liegt auf GitHub Pages. GitHub kann beim Aufruf technische Daten wie die IP-Adresse protokollieren (Datenschutzerklärung von GitHub). Wenn du Google Drive verbindest, lädt die Seite zusätzlich Skripte von Google, für die die Datenschutzerklärung von Google gilt.

Kontakt

Fragen zum Datenschutz stellst du über ein Issue auf GitHub.

Privacy policy

Last updated: 2 November 2026

In short

Eisenhower Matrix+ is a tool that runs entirely in your browser. There is no server and no account with us. We do not receive, store or sell any of your data.

Data in your browser

Your matrix is kept in your browser's storage (localStorage and IndexedDB) so that it is still there on your next visit. This data does not leave your device. You can delete it at any time by clearing the site data in your browser.

Files on your device

When you save or open a file, the tool only reads and writes that one file you chose yourself.

Google Drive (optional)

You can store your matrix in your own Google Drive. Only if you explicitly connect it, the following applies:

  • Access: The tool only uses the drive.file permission. It can only see and edit files you created with the tool or picked in it. It has no access to your other files.
  • Use: The data is only read and written to load and save your matrix. It goes directly from your browser to Google and back, not through any server of ours.
  • Storage: The access token stays in your browser only and expires after a short time. We do not store any Google data.
  • Sharing: We do not share Google data with third parties and do not use it for advertising, profiling or training AI models.
  • Revoking: You can revoke access at any time at myaccount.google.com/permissions.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Hosting

The site is hosted on GitHub Pages. GitHub may log technical data such as your IP address (GitHub privacy statement). If you connect Google Drive, the page also loads scripts from Google, covered by the Google privacy policy.

Contact

Ask privacy questions by opening an issue on GitHub.
